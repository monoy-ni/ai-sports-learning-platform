# 文档索引

本目录是产品范围、系统架构、接口契约和版本历史的统一文档来源。

## 产品范围

`0.1.0` 版本实现第一条可上线闭环：

1. 学生健康建档
2. AI 学期运动计划
3. 每日运动打卡
4. AI 每日反馈和运动卡片任务状态
5. 学生看板
6. 教师看板
7. AI 结课报告草稿和教师审核

`0.1.0` 不包含：社交动态、排行榜、家长端、医疗诊断、器械运动、多学校 SaaS 管理和真实校园跑接口接入。

## 文档分区

- `frontend/`：React 路由、UI 和接口使用规范。
- `backend/`：Spring Boot 领域模型、数据库、接口和安全设计。
- `ai/`：FastAPI 和 Deep Agent 任务设计。
- `api/`：OpenAPI 契约和接口变更规则。
- `adr/`：架构决策记录。
- `version/`：更新日志、路线图和版本说明。
- `plans/`：实施计划。
