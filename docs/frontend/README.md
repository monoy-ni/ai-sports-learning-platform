# 前端文档

前端是 React + TypeScript + Vite 应用。它是实际产品界面，不是营销落地页。登录后根据角色进入不同工作台：学生看到当前计划和打卡状态，教师看到班级风险与运动活跃度。

## 关键文档

- `frontend-architecture.md`：组件和功能边界。
- `routing-design.md`：路由地图和角色守卫。
- `state-management.md`：前端状态管理规则。
- `ui-design-guidelines.md`：视觉和交互规范。
- `api-contract-usage.md`：Spring Boot 接口调用规范。
